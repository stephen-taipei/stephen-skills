# AI Meeting - 多 AI 協作討論 (繁體中文版)

透過 Claude、Gemini、Codex 三方 AI 協作，為複雜決策提供多元觀點與共識建議。

## 適用場景

- 技術選型與架構決策（框架比較、資料庫選擇、部署策略）
- 商業策略與產品方向
- 需要正反辯論的爭議性問題
- 驗證想法或計畫的可行性
- 任何「一個人想不清楚」的問題

## 運作原理

1. Claude 作為主持人，將用戶的問題分別送給 Gemini 和 Codex
2. 三方各自獨立分析，避免群體思維
3. Claude 彙整三方觀點，找出共識與分歧，給出綜合建議

## 如何使用

直接使用 `/ai-meeting-tw` 指令加上討論主題即可。指令會自動處理查詢、彙整、輸出。

```
/ai-meeting-tw 新專案應該選 React 還是 Vue？團隊有 3 人，需要快速開發 MVP
```

## 前置需求

- `gemini` CLI 已安裝並設定（缺少時會降級為雙方或單方分析）
- `codex` CLI 已安裝並設定（缺少時會降級為雙方或單方分析）

## 產出格式

三方觀點對照表 + 共識點 + 分歧點 + 最終建議 + 行動項目
